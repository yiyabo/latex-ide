# T-05：UX 打磨与质量保障

> 阶段：M3 | 依赖：M2 完成 | 预计：3–5 天
> 目标：把能跑的闭环变成好用的产品，并建立回归防线。

## 范围

1. **端到端测试**（Playwright）
   - 黄金路径：注册 → 建项目（论文模板）→ 编辑 → 编译成功 → 选中 → 润色 → 接受 diff → 重编译；
   - 错误路径：编译失败 → 诊断列表点击跳转编辑器对应行；
   - patch 冲突路径：接受前改文档 → 409 提示正确展示。
   - AI 相关用例用录制/打桩的 provider（MSW 或 mock provider），保证 CI 可重复。
2. **UX 打磨清单**
   - 全量空状态（无项目/无文件/无选区/无对话/编译中/编译失败）；
   - 保存状态指示（未保存/保存中/已保存/保存失败重试）；
   - 编译状态全局可见（编辑器 tab、状态栏、AI 面板均可感知）；
   - 快捷键：Cmd+S 保存、Cmd+Enter 编译、Cmd+K 聚焦 AI 输入、Esc 关闭 diff 预览；
   - AI 回复中的 LaTeX 代码块高亮 + 复制按钮；
   - 长文档（≥5000 行）编辑与滚动无明显卡顿。
3. **安全与健壮性回归**
   - 复跑 T-03 全部恶意编译用例；
   - 复跑 T-04 prompt injection 用例；
   - API fuzz：非法 path、超大 body、畸形 patch operations；
   - 依赖漏洞扫描（pnpm audit）无 high/critical。
4. **可观测性**
   - 编译任务、AI 请求（token 用量、耗时）结构化日志；
   - 前端全局错误边界 + 服务端错误追踪（Sentry 或自托管替代，可配置关闭）。

## Definition of Done

- [ ] 黄金路径 E2E 在 CI 稳定通过（连续 5 次无 flake）；
- [ ] 全部空状态/加载态/错误态有设计且实现，无白屏；
- [ ] 快捷键全部生效且不冲突；
- [ ] 5000 行文档输入延迟主观无感（性能 profile 附证据）；
- [ ] 安全回归清单全绿；
- [ ] README 更新：本地启动、架构图、环境变量、测试命令；
- [ ] M2 首版成功标准（PLAN §6）由监督 Agent 完整走查通过。

## 给执行 Agent 的提示

- E2E 先于打磨写，打磨过程中防止改崩；
- 性能问题优先查 CodeMirror 扩展滥用和不必要的全树 re-render，再考虑虚拟滚动；
- 本任务是发布门槛，不允许"先合并后补测试"。
